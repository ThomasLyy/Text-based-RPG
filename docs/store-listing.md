## Full description

GAME NAME is a turn-based roguelite you can finish in about 20 minutes.

Three acts, each a branching map you see in full from the first step: fights, elites, events, shops and rest sites, then a boss. Health does not come back between fights, so every route is a bet.

- One hero, no classes: you start with a weapon and a spell, and build the rest from what each run offers.
- Readable fights: every enemy announces its next move. Attack, defend, cast, or drink a potion.
- 9 weapon families, 18 spells in 6 elements, three weights of armor with set bonuses.
- Every choice shows what it changes before you take it.
- 9 bosses; each run meets 3 of them.
- 10 difficulty levels, opened one by one by winning.
- Each run earns Ash, spent on new weapons, spells and events, and on permanent boosts.
- A run in progress is saved after every choice.

Free, with no ads and no purchases. Works offline. Collects no data.
